# Security policy / Politique de sécurité

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's
private reporting instead: *Security* tab → *Report a vulnerability*.

Include the affected file, the steps to reproduce, and the impact you
observed. You should get a first answer within a few days.

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour un problème de sécurité.
Utilisez le signalement privé de GitHub : onglet *Security* →
*Report a vulnerability*.

Indiquez le fichier concerné, les étapes pour reproduire et l'impact
constaté. Une première réponse vous parviendra sous quelques jours.
